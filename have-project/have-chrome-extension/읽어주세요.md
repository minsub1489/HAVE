# HAVE 크롬 확장 프로그램 — 개발용 (1.1.0 기준)

`팀원공유용_v3/10_HCI/have-chrome-extension`(HCI 최종본 1.1.0)을 복사해 온 **개발용 사본**입니다. 여기서부터 서버 연동판(1.2.0)으로 바꿔 갑니다. 원본은 `팀원공유용_v3`에 그대로 있고 고치지 않습니다.

원본과 다른 점은 두 가지이고 화면과 동작은 같습니다.

- `scripts/app.js`(925줄)를 화면별 파일로 나눴습니다(11/28). 코드를 옮기기만 했고, 옮긴 뒤 화면 74개의 출력과 클릭 흐름이 원본과 같은지 확인했습니다. 아래 "파일" 표에 담당자가 있습니다.
- `tests/model.test.js`를 넣었습니다(11-23에 만든 업무 규칙 테스트). `node --test tests/model.test.js`로 실행합니다.

지금은 아직 **브라우저 로컬 시연** 상태입니다(서버를 부르지 않음). 서버 호출로 바꾸는 방법과 순서는 저장소 루트의 `HAVE_최종_개발_가이드라인.md` 6절, 주고받는 JSON은 `docs/api.md`에 있습니다.

## 설치

1. Chrome 주소창에 `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더(`have-chrome-extension`)를 고릅니다.
4. 툴바의 HAVE 아이콘을 누르면 팝업이 열립니다. `사이드 패널` 또는 `새 탭에서 열기`로 전체 화면을 엽니다.

처음 열면 시연 데이터 6건이 만들어집니다. 사용 가이드(왼쪽 아래) → `시연 데이터 처음으로`로 언제든 되돌릴 수 있습니다. 팀원 판(11-23)과 저장소 이름이 달라(`have-extension-1123`) 기존 기록과 섞이지 않습니다.

## 11-23 팀원 피드백 반영 (팀원공유용_v2)

- 승인 효력과 최신 버전 여부를 나눴습니다. 효력은 `VALID`·`REVOKED`·`NONE`이고, 후속 버전이 있으면 ‘후속 버전 vN 있음’을 따로 보여 줍니다. 시연 데이터 ‘인공지능 윤리 에세이’는 v1 승인 철회 뒤 v2를 등록한 작업이라, v1 증명서의 공유 링크로 공개 검증을 열면 ‘v1 승인 철회 · 후속 버전 v2 있음 · 선택 파일은 v1과 일치’가 함께 보입니다.
- 수정본 재제출 화면에서 근거자료와 AI 사용 신고를 고칠 수 있습니다. 직전 버전과 근거(근거자료의 유형·주소·파일 해시, AI 사용 신고)가 다르면 새 버전은 ‘이해 확인 대기’에서 시작하고, 문항마다 이전 답변을 ‘v1 답변 · 참고’로 보여 줍니다. 답변을 다시 제출하면 검토자에게 ‘재제출’ 알림이 갑니다. 근거가 그대로면 이전처럼 답변이 이어지고 바로 ‘검토 대기’가 됩니다.

화면 파일이 이벤트를 받는 방법(`app.js`에 정의):

| 함수 | 쓰임 |
| --- | --- |
| `addAction(이름 또는 이름 목록, run)` | `data-action="이름"`인 버튼을 눌렀을 때. `run(button, work, action)` |
| `addActionPrefix(접두사, run)` | 이름이 그 접두사로 시작하는 버튼 |
| `addHandler(종류, match, run)` | `click` · `input` · `change` · `drop` · `submit`. `match(event)`가 참이면 `run(event)`. `match`는 `await` 없이 바로 답해야 함 |
| `addRoleDecision(mode, run)` | 검토 · 승인 화면의 결정 버튼(`role.js`) |

## 한계

서버·로그인·전자서명은 없습니다. 모든 기록은 이 브라우저에만 저장되므로 공유 링크와 공개 검증도 링크를 만든 브라우저에서만 열립니다. 증명서의 전자서명은 ‘확인 불가’로 표시하고, 증명서 내용 해시(payload)만 계산합니다.

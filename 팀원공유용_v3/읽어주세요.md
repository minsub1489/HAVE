### 04장 순서 조정 (11-23)

UC01 · UC02 상태 다이어그램(11-04 원본)을 04장 맨 끝에서 상태 ① 확대 바로 뒤(79쪽)로 옮겼습니다. 상태 ①의 앞부분(작업 생성 ~ 검토 요청 직전)을 UC01 · UC02 기준으로 자세히 본 그림이라 ① 옆에 두었습니다. 그래서 상태 ② ~ ⑦은 80 ~ 85쪽이 됐고, 목차(32쪽)와 04장 구분 쪽(74쪽)의 목록도 이 순서로 고쳤습니다. 05장 이후 쪽 번호는 그대로입니다. 위 표의 04장 쪽 번호는 옮긴 뒤 기준입니다. 79쪽 그림은 객체별 상태 ①과 다른 유스케이스 단위 그림이라 번호를 붙이지 않고 "참고 — 등록 과정의 상태 (UC01 · UC02)"로 제목을 바꿨습니다. 상태 ② ~ ⑦ 제목에도 ⑥ · ⑦처럼 해당 유스케이스를 괄호로 붙였습니다(②: UC03 · UC04, ③: UC05, ④: UC06 · UC10, ⑤: UC07). 목차(32쪽)와 04장 구분 쪽(74쪽)의 목록도 같은 제목으로 맞췄습니다.

### 확장 프로그램 `have-chrome-extension`

- 승인 효력과 최신 버전 여부를 나눠 표시하고(증명서 · 공개 검증 · 버전 이력 · 승인한 버전 목록), 수정본 재제출 화면에서 근거자료와 AI 사용 신고를 고칠 수 있게 했습니다. 근거가 바뀌면 재제출 뒤 이해 확인 화면으로 이어지고 문항마다 이전 답변이 참고로 보입니다.
- 시연 데이터 "인공지능 윤리 에세이"는 v1 승인 철회 뒤 v2를 등록한 작업으로 바꿨습니다. v1 증명서의 공유 링크로 공개 검증을 열면 철회와 후속 버전이 함께 보입니다. 이미 설치해 쓰던 브라우저에서는 사용 가이드의 `시연 데이터 처음으로`를 눌러야 바뀐 시연 데이터가 보입니다.
- 모델 테스트 8개(근거 변경 재제출 테스트 추가)와 화면 흐름 테스트(근거 변경 재제출, 철회된 v1 공개 검증 포함)를 모두 통과했습니다.
